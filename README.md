# 🏥 Smart Hospital Bed Demand Predictor
## 📌 Project Overview
Smart Hospital Bed Demand Predictor is an AI-based healthcare project that predicts emergency hospital bed requirements using Machine Learning and NLP techniques.
The system analyzes:
- Patient complaints
- ER crowd levels
- Historical emergency data
and predicts the number of beds required in hospitals.
---
## 🚀 Features
- Emergency complaint urgency prediction
- ER crowd level analysis
- Bed demand prediction using Machine Learning
- Data visualization using Streamlit
- Interactive hospital dashboard
---
## 🛠 Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
